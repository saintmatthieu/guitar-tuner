# PESTO

We wired [PESTO](https://github.com/SonyCSLParis/pesto) into the benchmark and a test
app. It's trained on voice and does poorly on guitar — mainly octave errors on the
open low strings.

[`pesto-work`](https://github.com/saintmatthieu/pesto-work) holds an unfinished
experiment to fine-tune it on guitar. It's on hold, since recent improvements to our
own algorithm may already suffice. Revive it if they don't.
